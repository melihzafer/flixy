# App Store Connect metadata

Drop these strings into App Store Connect when the app listing is created.
Update the dates in `release-notes.md` per release.

## Files

- `name.txt` — App name (max 30 chars)
- `subtitle.txt` — Subtitle (max 30 chars, EN-US storefront)
- `promotional-text.txt` — Promotional text (max 170 chars; can change without resubmission)
- `description.txt` — Long description (max 4000 chars)
- `keywords.txt` — Comma-separated keywords (max 100 chars)
- `support-url.txt` — Support URL
- `marketing-url.txt` — Marketing URL
- `privacy-url.txt` — Privacy policy URL
- `release-notes.md` — Per-version release notes (one h2 heading per version)

## Screenshots

App Store screenshots will be generated by Maestro flow recordings during the
launch ceremony (see `docs/HUMAN_BLOCKERS.md` and `mobile-release-pilot` skill).
Store them under `apps/mobile/store/app-store/screenshots/<locale>/<device>/`.

Required device sizes: iPhone 6.7" (iPhone 15 Pro Max), iPhone 6.5", iPad 12.9".
