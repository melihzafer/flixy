# Google Play Store metadata

Drop these strings into the Play Console listing.

## Files

- `title.txt` — App title (max 30 chars)
- `short-description.txt` — Short description (max 80 chars)
- `full-description.txt` — Full description (max 4000 chars)
- `release-notes.md` — Per-version "What's new" (max 500 chars per version)

## Graphics

- Feature graphic 1024x500 PNG
- Phone screenshots 1080x1920 (min 2, max 8)
- Tablet screenshots optional

Generated from Maestro recordings during the launch ceremony, stored under
`apps/mobile/store/play-store/screenshots/<locale>/`.

## Categorization

- Application type: Apps
- Category: Entertainment
- Tags: Movies, Streaming, TV
- Content rating: Teen (occasional mild themes from movie metadata)
- Target audience: 13+

## Data safety form

Mirror the privacy policy. Data collected:
- Email address (optional, for account)
- App activity (swipes, watchlist) — used for personalization
- Crash logs — used for diagnostics

All data encrypted in transit. Users can request deletion via
privacy@flixy.app.
