04 — My Read
Option A is the stronger bet.
★ Pick
PP Editorial New + Inter
PP Editorial New's italic has something GT Sectra lacks: it reads as software-native as well as cinematic. At 22–28px on a card it's unmistakably editorial but not newspaper. Inter is the obvious UI partner — it disappears at small sizes in the best possible way. The tension between a very expressive display face and a totally neutral UI font is exactly the Criterion-meets-app contrast you're after.
GT Sectra + GT America
Sectra is magnificent — ink-traps at large sizes are genuinely beautiful — but paired with GT America it can read "Monocle magazine app" rather than "premium consumer product." The family feel between both Grilli faces reduces the tension and makes the product feel slightly publishing-house rather than entertainment. Still great; lower risk; more expected from this brief.
Licensing note
PP Editorial New: available from Pangram Pangram Foundry, from ~$49 (desktop) / ~$149 (web). GT Sectra + GT America: from Grilli Type, ~$200–$400 per style depending on usage tier. Both are one-time purchases for the prototype phase.
On the prototype approximations
This page uses Instrument Serif italic (for PP Editorial New) and Newsreader italic (for GT Sectra) as web substitutes. They're close but not identical — particularly at larger sizes the licensed fonts have significantly more character. The prototype should be re-rendered with actual files once licensed.
Approximations used on this page:
PP Editorial New italic → Instrument Serif italic (Google Fonts)  ·  GT Sectra italic → Newsreader italic (Google Fonts)  ·  Inter → Inter (Google Fonts, exact match)  ·  GT America → Space Grotesk (Google Fonts, proportionally similar).
